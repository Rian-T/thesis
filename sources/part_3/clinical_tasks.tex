A clinical study records a fixed set of variables in an electronic case report
form (eCRF). These values are spread across reports written throughout a
patient's care and must be assigned to the right fields. Since no open dataset
pairs French hospital reports with completed eCRFs, we train an extractor from
public and generated text that can run inside the hospital.
